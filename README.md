## 🎯 Goal

NullSpace는 AI의 핵심 원리를 이해하고, 구현과 실험을 통해 실제 문제를 해결하는 역량을 함께 쌓아갑니다.

- CS229·CS230을 중심으로 머신러닝·딥러닝 기본기 학습
- 매주 배운 내용에 대한 실습 및 실험 진행
- 발표와 코드 리뷰를 통해 서로의 생각과 궁금한 점 공유
- 이후 관심 있는 최신 AI 주제를 깊이 공부하고, 실전 프로젝트로 확장

<br>

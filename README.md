## NullSpace : From Null to Knowledge.

AI의 원리부터 구현과 실험까지 깊이 있게 탐구하는 스터디

<br>

## 🎯 Goal

NullSpace는 AI의 핵심 개념을 원리부터 이해하고, 이를 직접 구현하고 실험하며 검증하는 것을 목표로 합니다.

- 기초 수학과 확률부터 머신러닝의 문제 설정까지 연결
- 공식을 암기하기보다 직관 · 수식 · 코드로 원리 이해
- 핵심 알고리즘을 직접 구현하며 실제 동작 확인
- 실험과 결과 해석을 통해 이론과 구현 연결
- 이후 최신 기술에 대한 깊은 심화 학습을 위한 기반 구축

<br>

## 🔄 Study Process

Implementation Review → Review → Lecture → Question Talk → Next Practice → WIL
